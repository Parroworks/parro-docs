# Dashboard

The main dashboard gives doctors a real-time view of clinic activity.

## Sections

### Today's Queue
- Live appointment list for the current date
- Token numbers, patient names, visit type (in-clinic / online)
- Status: Waiting / In Progress / Done / Cancelled

### Appointment management
- Book, reschedule, cancel appointments
- View upcoming appointments by date
- Online consultation room links auto-generated

### Patient search
- Search by name or mobile number
- View full patient history
- Manage family members linked to one WhatsApp number

### Pharmacy alerts
- Low stock warnings
- Expiry alerts
- Quick link to medicine inventory
